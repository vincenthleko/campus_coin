## 🪙 Campus Coin – Capstone Project

> A peer-to-peer lending platform built to help students borrow and lend money with trust-based scoring.


---

### 📚 About the Project

**Campus Coin** is a decentralized-inspired web application that allows students to borrow and lend money securely within a student community. The system calculates a trust score based on lifestyle behaviors, login activity (Uber, UberEats, Takealot, Checkers60), and repayment history to recommend creditworthiness.

This project was created as part of the 4IR Work Readiness Programme capstone project initiative to apply real-world backend and frontend development skills.

---

### 🚀 Features

* 🧮 **Trust score engine** – calculates a score based on user behavior
* 🔐 User authentication (login/register)
* 📊 Personalized dashboard for borrowers and lenders
* 🤝 Simulated ETH transactions for lending and repayment
* 📡 API integration (mocked lifestyle activity)
* 🔎 Role-based dashboards: Richard (borrower) & Brian (lender)

---

### 🛠️ Tech Stack

* **Backend**: Node.js, Express.js
* **Frontend**: Alpine.js
* **Database**: SQLite
* **Tools**: Git, GitHub, VS Code
* **Concepts**: Smart contract logic simulation, credit scoring, API mocking
